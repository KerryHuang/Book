# 關卡一：團隊共識協定

## 🎯 目標

快速建立屬於你們小組的 **3 條團隊工作共識**， 確保在後續任務中能更順暢協作與溝通。

------

## 🧭 任務說明

1. 小組討論並決定 **3 條具體、可執行的共識（不一定需要在此工作坊執行）**。  
2. 內容可聚焦在以下三大方向：  

| 類別     | 共識範例參考                              |
| :------- | :---------------------------------------- |
| 會議效率 | 每場討論不超過 3 分鐘，有衝突時輪流做決策 |
| 溝通文化 | 對事不對人，意見不同先釐清目標再討論方法  |
| 行為準則 | 不對人罵髒話                              |

1. 完成後請在 Jira 關卡一：團隊共識建立 之下新增三張 child work item(子系工作項目)

   1. Summary/標題格式：  

      1. 團隊共識 - 會議效率 - [各組討論內容]
      2. 團隊共識 - 溝通文化 - [各組討論內容]
      3. 團隊共識 - 行為準則 - [各組討論內容]

      

2. 將 child work item(子系工作項目) 移動至 **Done(完成)** 欄後，即可獲得本關密碼碎片 🔐。

------

🔐 密碼提示
完成任務並將 child work item(子系工作項目) 移動至 **Done(完成)** 後， 關卡一：團隊共識建立 單子的密碼欄位將自動出現密碼碎片。
