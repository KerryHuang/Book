# 關卡三：關鍵人物檔案

# 專案 RACI 矩陣：智慧搜尋功能

------

## 📚 RACI 說明

RACI 矩陣是一種專案管理工具，用來明確劃分團隊成員在各項任務中的角色與責任

| 字母  | 意義        | 說明                         |
| :---- | :---------- | :--------------------------- |
| **R** | Responsible | 負責執行任務的人（可多人）   |
| **A** | Accountable | 最終負責與決策者（只能一人） |
| **C** | Consulted   | 需要諮詢意見的人             |
| **I** | Informed    | 需要被告知進度的人           |


**關鍵原則：**

- 每個任務必須有一個明確的 A (Accountable)
- R (Responsible) 可以有多人
- 避免過多的 C 和 I，會降低效率

------

## 👥 專案角色說明

搜尋「**角色職責說明**」找到完整的角色定義文件。

**專案角色：**

- Product Owner (PO)
- Tech Lead (TL)
- Backend Developer (BE)
- Frontend Developer (FE)
- QA Engineer (QA)

------

## 📊 RACI 矩陣範例

| 任務         | Product Owner | Tech Lead | Backend Dev | Frontend Dev | QA   |
| :----------- | :------------ | :-------- | :---------- | :----------- | :--- |
| **需求釐清** | A             | C         | C           | I            | I    |
| **技術設計** | C             | A         | R           | R            | C    |
| **後端開發** | I             | C         | A/R         | I            | I    |
| **前端開發** | I             | C         | I           | A/R          | I    |
| **整合測試** | C             | C         | C           | C            | A/R  |
| **用戶驗收** | A             | I         | I           | I            | C    |

## 📝 下一步

1. 此 Confluence 頁面下有各組分頁，找到自己的組別頁面 Team0 專案 RACI 矩陣
2. 檢視每個任務，討論哪個角色應該負責什麼 （別忘了有 AI 助教可以幫忙）
3. 確保每行都有一個 A，調整上表符合團隊共識
4. 完成空白表格的 RACI 矩陣，僅需填字母
5. 前往 Jira 關卡三：關鍵人物檔案 之下新增一張 child work item(子系工作項目)
   1. Summary(標題格式)：  
      1. 完成專案 RACI 矩陣
6. 將 child work item(子系工作項目) 移動至 **Done(完成)** 欄後，即可獲得本關密碼碎片 🔐。

------

🔐 密碼提示
完成任務並將 child work item(子系工作項目) 移動至 **Done(完成)** 後， 關卡三：關鍵人物檔案 單子的密碼欄位將自動出現密碼碎片。
