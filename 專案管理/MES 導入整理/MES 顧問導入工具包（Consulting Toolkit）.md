# MES 顧問導入工具包（Consulting Toolkit）

以下整理為 **MES 顧問導入工具包（Consulting Toolkit）**。
 此工具包通常是 **MES 公司顧問團隊的標準導入方法論**，包含 **流程文件、模板、檢查表、訪談表、導入計畫**。

整體結構分為 **6 個核心工具包**。

------

# MES 顧問核心工具包（Consulting Toolkit）

| 工具包    | 目的         | 主要內容               |
| --------- | ------------ | ---------------------- |
| Toolkit 1 | 客戶導入評估 | 客戶成熟度評估         |
| Toolkit 2 | 流程盤點     | 現場流程訪談           |
| Toolkit 3 | Master Data  | 主資料模板             |
| Toolkit 4 | 系統導入規劃 | Implementation Plan    |
| Toolkit 5 | 系統測試     | UAT Test               |
| Toolkit 6 | 上線與改善   | Go-live / Optimization |

------

# Toolkit 1

# 客戶導入評估表（MES Readiness Assessment）

導入前先評估企業成熟度。

| 評估項目 | 評估內容       | 分數 |
| -------- | -------------- | ---- |
| 生產流程 | 是否有 SOP     | 1~5  |
| 生產排程 | 是否有排程     | 1~5  |
| 工單管理 | 是否有工單     | 1~5  |
| 生產回報 | 是否有報工     | 1~5  |
| 品質管理 | 是否有檢驗     | 1~5  |
| 設備管理 | 是否有機台資料 | 1~5  |
| 數據管理 | 是否有數據     | 1~5  |
| IT能力   | IT人員         | 1~5  |

評估結果：

| 分數  | 等級 |
| ----- | ---- |
| 0~15  | 初級 |
| 16~30 | 中級 |
| 31~40 | 進階 |

# 如果你是 MES 產品公司

我會非常建議你們建立 **三個標準工具**：

### 1️⃣ MES 導入標準流程（SOP）

```
導入 → 流程 → Master Data → 系統 → 測試 → 上線
```

------

### 2️⃣ MES Master Data Template

Excel 模板。

------

### 3️⃣ MES 流程藍圖

例如：

```
訂單
↓
工單
↓
排程
↓
報工
↓
品質
```
